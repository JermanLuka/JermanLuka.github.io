Freelance full-stack work on the web application for BeeConn, a commercial hive
monitoring system. Beekeepers get scales and a weather station at the hives; the
application turns those readings into charts, tables, and reports.

## What I built

- Integrated Stripe for payment processing, including the package and payment
  models.
- Built the data layer with Entity Framework using a code-first approach.
- Implemented access control and user permissions across multiple components.
- Built the graphing of IoT device measurements.

## Stack

C#, .NET, JavaScript, MVC, MySQL.
